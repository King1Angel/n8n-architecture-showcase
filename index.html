Backoff Exponencial y Retries en LLM

Para mitigar respuestas 429 Rate Limit o 503 Service Unavailable durante ráfagas de consultas, se implementó política de reintentos con 3 saltos exponenciales (2500ms).

const retryPolicy = { retryOnFail: true, maxTries: 3, waitBetweenTries: 2500 // ms exponencial };
// Desacoplamiento de Binarios

Subflujo Helper para Hojas de Cálculo (.xlsx)

Los LLMs fallan procesando binarios crudos. Un micro-workflow dedicado descarga el archivo real desde Google Drive, lo convierte a JSON estructurado y envía solo las celdas necesarias.

POST /webhook/leer-excel-drive → DriveDownload(alt=media) → SpreadsheetParser(.xlsx/.csv) → ContextLimiter(sampleRows: 250)
// Observabilidad de Ciclo Cerrado

Bucle DevOps Auto-Sanador en n8n

El Agente DevOps no depende de supervisores humanos. Lee excepciones en SQLite en caliente, analiza el JSON del flujo y reconfigura parámetros mediante la API pública de n8n.

ErrorTrigger → SQLite StackTrace Inspector → DevOpsAgent(AutoPatch) → n8n Public API Update → Service Ready
// Seguridad & Gobernanza

Protocolo Human-in-the-Loop Obligatorio

Acciones irreversibles (despacho de correos o borrado de eventos) exigen una confirmación explícita con borrador estructurado en 4 puntos antes de invocar la API.

Prompt Solicitud → Formular Borrador → Presentar en Chat → ¿Aprobado? [ SI → EnviarCorreo() | NO → Abortar ]
